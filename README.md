# +Ultra Online

+Ultra Online is an unofficial, noncommercial Chrome extension that improves
the browsing and deck-building experience on
[`uvsultra.online`](https://uvsultra.online/).

It provides an accessible dark search view, reorganized keyword and advanced
filters, deck sorting and forum-code helpers, and selectable validated
alternate card artwork.

## Install for development

1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode**.
3. Select **Load unpacked**.
4. Choose this repository directory.
5. Visit `https://uvsultra.online/`.
