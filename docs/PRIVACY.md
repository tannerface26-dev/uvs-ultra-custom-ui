# +Ultra Online Privacy Policy

Last updated: September 20, 2026

+Ultra Online is an unofficial browser extension for
`https://uvsultra.online/`.

## Data handled

+Ultra Online reads the UVS Ultra pages on which it runs so it can restyle the site,
organize search controls, enhance deck lists, generate card-qualified forum
code, and offer validated alternate card artwork. This processing occurs
locally in the user's browser.

The extension stores two kinds of preferences in the browser's local storage:

- the selected light or dark view; and
- the selected artwork ID for a card in a deck.

These preferences do not contain account credentials or payment information.

## Data sharing

+Ultra Online does not transmit page contents, deck contents, account credentials,
browsing history, or stored preferences to the developer. It contains no
analytics, advertising, or tracking code.

Alternate card images are loaded over HTTPS from a commit-pinned repository on
GitHub's raw-content service. GitHub may receive ordinary network request data,
such as the user's IP address, browser user agent, and the URL of the specific
artwork file requested, under GitHub's own privacy terms. The artwork URL may
identify the card image being displayed. Image requests use a no-referrer
policy and do not include the UVS Ultra page URL, deck contents, or stored
preferences.

## Limited use

+Ultra Online handles website content only to provide the user-facing features
described in its Chrome Web Store listing. Its use of information complies
with the Chrome Web Store User Data Policy, including the Limited Use
requirements. The extension does not use handled data for advertising,
profiling, credit decisions, or sale to third parties, and does not permit
humans to read private user data.

## Retention and deletion

Preferences remain in the browser's local storage until the user clears site
data or removes them through browser controls. The developer does not receive
or retain these preferences.

## Changes

Material changes to this policy will be published at the policy URL shown in
the Chrome Web Store listing.

## Contact

Privacy questions may be submitted through the [support
channel](https://tannerface26-dev.github.io/uvs-ultra-custom-ui/SUPPORT.html).
Do not include sensitive information in a public issue; request a private
contact method when needed.
